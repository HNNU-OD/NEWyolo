# Ubuntu 训练上传说明（YOLOv8m，五类）

GitHub 仓库 HNNU-OD/NEWyolo 当前已有 ultralytics 源码。另将本地 D:/newYOLO 下的以下内容上传到服务器克隆目录，保持相对目录结构：

```text
NEWyolo/
  ultralytics/                       GitHub 已有，包含 pyproject.toml
  datasets/insulator_merged_yolo/
    images/                         3370 张图片
    labels/                         3370 份 TXT（包括空 TXT）
    data_yolov8.yaml                 当前五类定义
    train.txt
    val.txt
    test.txt
  insulator_project/
    train_server.py                  使用本次更新版本，可选 --model
    weights/yolov8m.pt               官方初始预训练权重，约 52 MB
```

必须使用 D:/newYOLO/datasets/insulator_merged_yolo 的五类数据，不能误传 D:/traindata 下原始九类数据。当前 train/val/test 图片数为 2848/383/139，共 9532 个框。空标签是数据的一部分，不要删除。

源码和小型脚本可放 GitHub；数据集和权重可以通过服务器文件上传、SFTP 或 scp 直接传到服务器，不必放进 GitHub。无需上传 Windows .venv、.git、backups、__pycache__、*.cache、历史 runs 和日志。从官方预训练权重重新训练不需要本地 best.pt；本说明不做断点续训。

## Ubuntu 安装和检查

先激活服务器的 NVIDIA GPU PyTorch 环境。若没有，请先创建 Linux Python 环境，再按 https://pytorch.org/get-started/locally/ 选择适合服务器 GPU/驱动的 CUDA 版 PyTorch；不要复制 Windows 虚拟环境，也不要在未知 GPU/驱动条件下固定 CUDA 安装版本。

首次下载源码：

```bash
git clone https://github.com/HNNU-OD/NEWyolo.git
cd NEWyolo
```

把上述 datasets 和 insulator_project 内容上传到当前 NEWyolo 目录后，执行：

```bash
python -m pip install -e ./ultralytics
python -m pip check
nvidia-smi
python -c "import torch; print(torch.__version__); print('CUDA:', torch.cuda.is_available()); assert torch.cuda.is_available(), 'GPU PyTorch is required'"
python insulator_project/train_server.py --model yolov8m.pt --check-only
```

check-only 检查全部文件路径、图标配对和类别，不验证服务器 GPU 运算能力，也不重新进行图片解码。脚本自动将 YAML 中的 Windows path 替换为服务器真实目录，并生成 data_server.yaml，无需手动修改盘符。

## 先试跑一轮，再正式训练

```bash
python insulator_project/train_server.py --model yolov8m.pt --epochs 1 --batch 4 --workers 4 --device 0 --name server_v8m_check
```

该命令成功后，再执行 100 轮。下面使用 nohup 将训练与 SSH 终端断开隔离，日志保存为 server_v8m_100.log。请只启动一次：

```bash
nohup python -u insulator_project/train_server.py --model yolov8m.pt --epochs 100 --batch 4 --workers 4 --device 0 --name server_v8m_100 > insulator_project/server_v8m_100.log 2>&1 &
tail -f insulator_project/server_v8m_100.log
```

两次命令均从 yolov8m.pt 初始权重开始微调；100 轮不会接着一轮试跑恢复。保持 batch=4 起步，显存不足时改成 2；若服务器的共享内存不足导致数据加载器报错，可将 workers 改为 0。

默认输入尺寸 640，关闭 AMP，与本地试验一致。结果保存在 insulator_project/runs/server_v8m_100/，最佳权重在其 weights/best.pt；如果同名目录已经存在，程序自动递增目录名，请以日志实际输出为准。

本地已核对上传路径与五类标签。Ubuntu 的实际依赖、显卡兼容性及训练仍需在目标服务器完成一轮验证。现有数据的跨集合近重复和标注一致性问题仍需后续处理。
